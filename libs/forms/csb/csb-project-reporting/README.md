# CSB Project Reporting

Multi-step form flow generated by `nx g @garage/plugin:form-flow`.

| Step           | Route            | Component                     |
| -------------- | ---------------- | ----------------------------- |
| Project        | `project`        | `ProjectStepComponent`        |
| Buses          | `buses`          | `BusesStepComponent`          |
| Infrastructure | `infrastructure` | `InfrastructureStepComponent` |
| Review         | `review`         | `ReviewStepComponent`         |

- **State:** `CsbProjectReportingState` (`src/lib/csb-project-reporting.state.ts`) holds the data across steps. Replace its `submit()` with a real API call.
- **Data shape:** `src/lib/csb-project-reporting.model.ts`. Each step starts with one placeholder `example` field; swap in that step's real fields.
- **Routing:** steps after the first are guarded, so users can't skip ahead.

Run `nx test csb-project-reporting` to run this flow's unit tests.
