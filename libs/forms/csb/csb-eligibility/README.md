# CSB Eligibility and Scrap, Sell, Donate Statement

Multi-step form flow generated by `nx g @garage/plugin:form-flow`.

| Step        | Route         | Component                  |
| ----------- | ------------- | -------------------------- |
| Applicant   | `applicant`   | `ApplicantStepComponent`   |
| Buses       | `buses`       | `BusesStepComponent`       |
| Disposition | `disposition` | `DispositionStepComponent` |
| Review      | `review`      | `ReviewStepComponent`      |

- **State:** `CsbEligibilityState` (`src/lib/csb-eligibility.state.ts`) holds the data across steps. Replace its `submit()` with a real API call.
- **Data shape:** `src/lib/csb-eligibility.model.ts`. Each step starts with one placeholder `example` field; swap in that step's real fields.
- **Routing:** steps after the first are guarded, so users can't skip ahead.

Run `nx test csb-eligibility` to run this flow's unit tests.
