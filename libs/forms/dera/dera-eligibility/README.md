# DERA Eligibility Statement

Multi-step form flow generated by `nx g @garage/plugin:form-flow`.

| Step      | Route       | Component                |
| --------- | ----------- | ------------------------ |
| Applicant | `applicant` | `ApplicantStepComponent` |
| Fleet     | `fleet`     | `FleetStepComponent`     |
| Review    | `review`    | `ReviewStepComponent`    |

- **State:** `DeraEligibilityState` (`src/lib/dera-eligibility.state.ts`) holds the data across steps. Replace its `submit()` with a real API call.
- **Data shape:** `src/lib/dera-eligibility.model.ts`. Each step starts with one placeholder `example` field; swap in that step's real fields.
- **Routing:** steps after the first are guarded, so users can't skip ahead.

Run `nx test dera-eligibility` to run this flow's unit tests.
