# DERA Scrappage Statement

Multi-step form flow generated by `nx g @garage/plugin:form-flow`.

| Step               | Route                | Component                        |
| ------------------ | -------------------- | -------------------------------- |
| Vehicles           | `vehicles`           | `VehiclesStepComponent`          |
| Scrappage Evidence | `scrappage-evidence` | `ScrappageEvidenceStepComponent` |
| Review             | `review`             | `ReviewStepComponent`            |

- **State:** `DeraScrappageState` (`src/lib/dera-scrappage.state.ts`) holds the data across steps. Replace its `submit()` with a real API call.
- **Data shape:** `src/lib/dera-scrappage.model.ts`. Each step starts with one placeholder `example` field; swap in that step's real fields.
- **Routing:** steps after the first are guarded, so users can't skip ahead.

Run `nx test dera-scrappage` to run this flow's unit tests.
